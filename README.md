# AI-Powered Virtual Personal Finance Assistant

An end-to-end Artificial Intelligence project developed during an Artificial Intelligence Industry Internship at Geonixa.

The notebook combines expense categorization, banking chatbot intent detection, and tabular transaction anomaly/fraud modeling. It also benchmarks lightweight classical ML approaches against a fine-tuned DistilBERT intent classifier and demonstrates dynamic quantization of the trained transformer.

## Project Highlights

- Expense categorization using **TF-IDF + Linear SVM**
- Banking intent classification using **Multinomial Naive Bayes** and **Logistic Regression**
- Banking intent fine-tuning using **DistilBERT**
- Transaction anomaly labeling using **Isolation Forest**
- Class balancing using **SMOTE**
- Fraud/anomaly classification benchmarking using **Logistic Regression** and **XGBoost**
- Dynamic INT8 quantization of the fine-tuned DistilBERT model
- Operational profiling using training time and inference latency (P50/P99)

## Technologies

## Project Workflow

### 1. Data ingestion

The notebook loads three public datasets:

- **Expense categorization:** `j-convey/BankTextCategorizer` CSV mirror and `rajeshradhakrishnan/fin-transaction-category`
- **Banking intent detection:** Hugging Face `mteb/banking77`
- **Tabular transaction data:** a public GitHub mirror of `bank_transactions_data_2.csv`

The notebook reports:
- Expense dataset: **3,470 rows**
- Banking77: **9,993 training rows** and **3,076 test rows**
- Tabular transaction dataset: **2,512 rows**

### 2. Text preprocessing

Two preprocessing paths are used:

- **Classical ML:** lowercase text, remove punctuation, normalize whitespace
- **Transformer:** normalize whitespace while preserving casing and punctuation

### 3. Expense categorization

A TF-IDF + Linear SVM pipeline is trained on the expense-description dataset.

Recorded notebook results:

| Metric | Result |
|---|---:|
| Accuracy | 87.75% |
| Weighted F1 | 0.8763 |
| P50 latency | 0.76 ms |
| P99 latency | 1.21 ms |
| Training time | 0.17 s |

### 4. Banking chatbot intent detection

Classical baselines are trained on the Banking77 corpus.

Recorded notebook results:

| Model | Macro F1 |
|---|---:|
| Multinomial Naive Bayes | 0.7843 |
| Logistic Regression | 0.8597 |

For the Logistic Regression intent model, the notebook reports:

- P50 latency: **1.07 ms**
- P99 latency: **7.80 ms**

### 5. DistilBERT fine-tuning

The notebook fine-tunes `distilbert-base-uncased` for 77 Banking77 intent classes.

Configuration recorded in the notebook:

- Learning rate: `2e-5`
- Batch size: `16`
- Epochs: `1`
- Weight decay: `0.01`
- Output directory: `./results`

The recorded training output reports:

- Global steps: **625**
- Training loss: **3.43865**
- Training runtime: approximately **1931.45 s**

The notebook does not report a final validation accuracy or F1 score for the fine-tuned DistilBERT model, so this repository does not claim one.

### 6. Transaction anomaly / fraud modeling

The notebook derives the `IsFraud` label using **Isolation Forest** with:

- `n_estimators=100`
- `contamination=0.05`
- `random_state=42`

The resulting class split is approximately:

- Normal: **94.98%**
- Anomaly/Fraud label: **5.02%**

SMOTE is then applied only to the training split, balancing the training set from 2,009 rows to 3,816 rows.

Recorded benchmark results:

| Model | Macro F1 | Train time | P50 latency | P99 latency |
|---|---:|---:|---:|---:|
| Logistic Regression | 0.8866 | 0.02 s | 0.99 ms | 2.07 ms |
| XGBoost | 0.9392 | 0.10 s | 1.75 ms | 3.80 ms |

**Important:** these `IsFraud` labels are anomaly labels generated by Isolation Forest, not ground-truth fraud labels supplied by a fraud investigation or financial institution. The benchmark therefore measures performance against the notebook's derived anomaly labels.

### 7. Model quantization

The fine-tuned DistilBERT checkpoint at:

`./results/checkpoint-625`

is dynamically quantized with PyTorch to INT8 for the linear layers, and the resulting state dictionary is saved as:

`quantized_banking_model.pth`

## How to Run

### Google Colab

1. Open the `.ipynb` file in Google Colab.
2. Run the cells from top to bottom.
3. The notebook downloads the public datasets during execution.

### Local Python environment

Create a virtual environment, install the dependencies, and run the notebook with Jupyter.

```bash
python -m venv .venv
```

Activate the environment:

**Windows**
```bash
.venv\Scripts\activate
```

**macOS/Linux**
```bash
source .venv/bin/activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Start Jupyter:

```bash
jupyter notebook
```

Open:

`AI_Powered_Virtual_Personal_Finance_Assistant.ipynb`
