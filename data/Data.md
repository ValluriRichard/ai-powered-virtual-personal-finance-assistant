# Data

The project notebook downloads public datasets at runtime and does not require committing the raw datasets to this repository.

Referenced sources include:

- Hugging Face `mteb/banking77`
- Hugging Face `rajeshradhakrishnan/fin-transaction-category`
- `j-convey/BankTextCategorizer` CSV mirror
- `mehedihasanmir/Bank-Transaction-Dataset-for-Fraud-Detection` CSV mirror

Keeping raw datasets out of the repository makes the project lighter and avoids unnecessarily redistributing dataset files.
